# CLAUDE.md — instructions for Claude Code

CouchSync: a Qt 6 + libmpv desktop media player with watch-together sync, plus a small Node/TS room server. Public GitHub repo.

## Read first
1. `docs/DESIGN.md` — source of truth for the design. If code and design disagree, ask before changing either; record decisions in its Decisions log.
2. `docs/ROADMAP.md` — build order. Work milestone by milestone; don't jump ahead (e.g. no streaming work before M2 is done).

## Layout (planned)
```
client/      Qt 6 / C++20 app (CMake, vcpkg)
  src/player/    libmpv wrapper + Qt Quick render item
  src/sync/      RoomClient, ClockSync, SyncEngine
  src/align/     Chromaprint fingerprinting + aligner
  src/stream/    WebRTC tunnel, host Range server, viewer proxy
  qml/           UI
server/      Node.js + TypeScript room server (ws), Dockerfile
tools/       sync simulator, aligner test tools
docs/
```

## Conventions
- Windows 11 is the main dev/test machine (AMD RX 6600 XT, Ryzen 5 5600X). Keep code cross-platform anyway.
- C++20, Qt style for UI code; keep sync/align logic free of Qt where practical so it's unit-testable.
- Server: TypeScript strict mode, no framework beyond `ws`.
- Protocol changes: update `docs/PROTOCOL.md` in the same commit.
- Keep it simple. No feature beyond the current milestone without asking.
- Track progress in `PROGRESS.md` (what's done, what's next, known issues) at the end of each session.

## Testing
- Sync logic is tested with the headless simulator (latency, jitter, clock skew, loss), not only by hand.
- Aligner has a fixture test set; offsets must be within 50 ms.
- Never commit media files to the repo; fixtures are generated by scripts or downloaded from free sources (e.g. Blender open movies) at test time.
